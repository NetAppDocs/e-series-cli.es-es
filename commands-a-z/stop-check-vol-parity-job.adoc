= Detener la comprobación de paridad de volumen - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `stop check volume parity job` el comando detiene un trabajo de comprobación de paridad de un volumen en curso.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a cualquier matriz de almacenamiento individual, incluidas las matrices EF600, EF300, EF50 y EF80; siempre que estén instalados todos los paquetes SMcli.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento EF600, EF300, EF50 y EF80, debes tener el rol de Storage Admin.



[[syntax]]
== Sintaxis

[source, cli, subs="+macros"]
----
stop check volume parity job jobId=<job_id>;
----


[[parameters]]
== Parámetros

|===
| Parámetro | Descripción 


 a| 
`jobId`
 a| 
El ID de trabajo correspondiente al trabajo de comprobación de paridad del volumen que se desea detener. Este valor es obligatorio.

|===


[[minimum-firmware-level]]
== Nivel de firmware mínimo

11,80

= Mostrar la configuración del registro de auditoría - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `show auditLog configuration` el comando muestra la configuración del registro de auditoría de la cabina de almacenamiento.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a una E4000, E2800, E5700, EF600, EF300, EF50 y EF80 de almacenamiento individual. No funciona en matrices de almacenamiento E2700 o E5600.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol de Security Admin.



[[syntax]]
== Sintaxis

[source, cli]
----
show auditLog configuration
----


[[parameters]]
== Parámetros

Ninguno.



[[examples]]
== Ejemplos

[listing]
----

SMcli -n Array1 -c "show auditLog configuration;"

Logging level: All
Full policy: Overwrite
Maximum records: 30,000 count
Warning threshold: 90 percent

SMcli completed successfully.
----

= Mostrar la verificación de seguridad de datos del espejo de caché de la matriz de almacenamiento habilitada - CLI de SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `show storageArray cacheMirrorDataAssuranceCheckEnable` el comando devuelve el estado de preparación de la función verificación de garantía de datos de reflejo de la caché.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a cualquier matriz de almacenamiento individual, incluidas la E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 y EF80, siempre que todos los paquetes SMcli estén instalados.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol Storage Admin o Storage Monitor.



[[syntax]]
== Sintaxis

[source, cli]
----
show storageArray cacheMirrorDataAssuranceCheckEnable
----


[[parameters]]
== Parámetros

Ninguno.



[[minimum-firmware-level]]
== Nivel de firmware mínimo

8.41 Nuevo parámetro de comando.

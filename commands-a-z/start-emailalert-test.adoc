= Probar la configuración de alertas por correo electrónico - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `start emailAlert test` el comando permite probar la configuración de alertas mediante el envío de un mensaje de correo electrónico de muestra.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a una E4000, E2800, E5700, EF600, EF300, EF50 y EF80 de almacenamiento individual. No funciona en matrices de almacenamiento E2700 o E5600.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol de Storage Admin o Support Admin.



[[syntax]]
== Sintaxis

[source, cli]
----

start emailAlert test
----


[[parameters]]
== Parámetros

Ninguno.



[[examples]]
== Ejemplos

[listing]
----

SMcli -n Array1 -c "start emailAlert test;"

The sample alert message was successfully sent to the email addresses.

SMcli completed successfully.
----

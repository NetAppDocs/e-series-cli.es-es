= Iniciar el envío manual de AutoSupport de la matriz de almacenamiento - CLI de SANtricity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `start storageArray autoSupport manualDispatch` El comando inicia un paquete de soporte completo y el mensaje de ASUP para el paquete.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a una E4000, E2800, E5700, EF600, EF300, EF50 y EF80 de almacenamiento individual. No funciona en matrices de almacenamiento E2700 o E5600.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol Storage Admin.



[[context]]
== Contexto

Debido a la cantidad de tiempo que debe completarse, el comando devuelve correctamente si puede iniciar el proceso.



[[syntax]]
== Sintaxis

[source, cli]
----
start storageArray autoSupport manualDispatch
----


[[parameters]]
== Parámetros

Ninguno



[[minimum-firmware-level]]
== Nivel de firmware mínimo

8.63

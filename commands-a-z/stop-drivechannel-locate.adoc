= Detener la localización del canal de la unidad - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `stop driveChannel locate` el comando apaga las luces indicadoras de los soportes de unidades que se encendieron con el `start driveChannel locate` comando.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a cualquier matriz de almacenamiento individual, incluidas la E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 y EF80, siempre que todos los paquetes SMcli estén instalados.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol Storage Admin.



[[syntax]]
== Sintaxis

[source, cli]
----
stop driveChannel locate
----


[[parameters]]
== Parámetros

Ninguno.



[[minimum-firmware-level]]
== Nivel de firmware mínimo

6.10

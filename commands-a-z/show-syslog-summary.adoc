= Mostrar la configuración de syslog - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `show syslog summary` comando muestra la información de configuración de alertas de syslog.



== Cabinas compatibles

Este comando se aplica a una E4000, E2800, E5700, EF600, EF300, EF50 y EF80 de almacenamiento individual. No funciona en matrices de almacenamiento E2700 o E5600.



== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol de Storage Admin o Support Admin o Storage Monitor.



== Sintaxis

[source, cli]
----
show syslog summary
----


== Parámetros

Ninguno.



== Ejemplos

[listing]
----

SYSLOG SUMMARY
   Default facility: 3
   Default tag: StorageArray
   Syslog format: rfc5424
   Syslog Servers
      Server Address               Port Number
      serverName1.company.com      514
      serverName2.company.com      514

SMcli completed successfully.
----

= Detener la ubicación de la matriz de almacenamiento - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `stop storageArray locate` el comando apaga las luces indicadoras en la cabina de almacenamiento que fueron encendidas por el `start storageArray locate` comando.



== Cabinas compatibles

Este comando se aplica a cualquier matriz de almacenamiento individual, incluidas la E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50 y EF80, siempre que todos los paquetes SMcli estén instalados.



== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol Storage Admin.



== Sintaxis

[source, cli]
----
stop storageArray locate
----


== Parámetros

Ninguno.



== Nivel de firmware mínimo

6.10

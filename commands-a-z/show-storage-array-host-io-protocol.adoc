= Mostrar información del protocolo de E/S de host de la storage array - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
El `show storageArray hostIoProtocolInformation` comando muestra información sobre la configuración del protocolo de E/S para una matriz de almacenamiento específica.



[[supported-arrays]]
== Cabinas compatibles

Este comando es válido para una matriz de almacenamiento E4000, EF50 o EF80, siempre que estén instalados todos los paquetes SMcli.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, EF50 o EF80, debes tener el rol de Support Admin.



[[syntax]]
== Sintaxis

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== Parámetro

Ninguno.



[[minimum-firmware-level]]
== Nivel de firmware mínimo

12,00

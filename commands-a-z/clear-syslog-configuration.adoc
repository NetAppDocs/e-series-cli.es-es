= Borrar la configuración de syslog - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La `clear syslog configuration` el comando borra la información de alertas de syslog.



[[supported-arrays]]
== Cabinas compatibles

Este comando se aplica a una E4000, E2800, E5700, EF600, EF300, EF50 y EF80 de almacenamiento individual. No funciona en matrices de almacenamiento E2700 o E5600.



[[roles]]
== Funciones

Para ejecutar este comando en una matriz de almacenamiento E4000, E2800, E5700, EF600, EF300, EF50 o EF80, debes tener el rol de Storage Admin o Support Admin.



[[syntax]]
== Sintaxis

[source, cli]
----
clear syslog configuration
----


[[parameters]]
== Parámetros

Ninguno.



[[examples]]
== Ejemplos

[listing]
----

SMcli -n Array1 -c "clear syslog configuration;"

SMcli completed successfully.
----

== Nivel de firmware mínimo

8.40
